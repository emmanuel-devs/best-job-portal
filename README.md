# BEST JOB

A premium, responsive job portal concept built with Next.js 14, React, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included
- Responsive sticky navigation with mobile menu
- Forest-green editorial hero, job search, and category shortcuts
- Category filters and keyword search for sample roles
- Save/unsave job interactions
- Testimonials controls and career tools section
- Responsive layouts, reduced-motion support, accessible labels, and SEO metadata

## Prototype notes
This is a front-end portfolio concept. Listings, sign-in, job posting, applications, salary tools, and resume features use illustrative sample data or prototype messages. They are not connected to a production backend, authentication provider, or live job feed.

## Deployment
Import this repository into Vercel. Framework preset: Next.js. Build command: `npm run build`.
